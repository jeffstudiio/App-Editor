# استودیو خلاق — App-Editor 🎬

اپ همه‌کارهٔ خلاقیت برای موبایل (PWA فارسی، RTL): ویرایش ویدئو، بانک تمپلیت آماده، زیرنویس‌ساز، روتوش، دستیار هنری هوش مصنوعی و اکسپلور ایده.

> **نسخهٔ تست گوشی:** https://jeffstudiio.github.io/App-Editor/  
> (بعد از باز کردن، از منوی مرورگر «Add to Home Screen» بزن تا مثل اپ مستقیم اجرا شود)

## امکانات

- **بانک تمپلیت (تجربهٔ کپ‌کات):** ۸۷ قالب آماده در ۱۰ دسته (اینترو، لوگوموشن، ریلز، استوری، سینمایی، تایپوگرافی، محصول، مناسبت، موزیک، اسلایدشو). هر قالب با یک لمس یک ویدئوی کاملِ تمام‌شده پخش می‌کند و تو فقط رسانه‌ها (عکس/ویدئو/موزیک) را عوض می‌کنی.
- **رسانهٔ پیش‌فرض اورجینال:** ۱۰ پس‌زمینهٔ ویدئویی + ۹ قطعه موزیک، همه سینتی‌شده و بدون کپی‌رایت خارجی (اسکریپت‌ها: `scripts/gen-bg.py` و `scripts/gen-music.py`).
- **بانک من:** قالب‌سازی از فایل‌های خودت با ذخیرهٔ امن در IndexedDB و خروجی JSON برای انتشار.
- **ویرایشگر ویدئو، زیرنویس‌ساز فارسی، روتوش چهره، استودیو طراحی، اکسپلور و دستیار هنری AI** (OpenRouter / Gemini).
- **کراپ واقعی + تدوین بین‌ترکی:** کراپ منبع که در پیش‌نمایش و خروجی MP4 هر دو اعمال می‌شود، تعویض منبع کلیپ، انتقال کلیپ↔لایهٔ رویی (PiP) با z-order و برش خودکار روی نشانگرها.
- **عامل هوشمند تدوین (AI Agent):** دستور فارسی بده («ریلز لوکسِ قبل و بعد بساز…») — برنامهٔ عملیاتی ساخت‌یافته می‌سازد، پیش‌نمایش می‌بینی و با تأیید تو واقعاً روی تایم‌لاین اجرا می‌کند (۲۹ دستور واقعی: تریم/برش/فیلتر/ترنزیشن/موسیقی/عنوان/کی‌فریم/کراپ واقعی/تعویض منبع/انتقال بین‌ترک/تولید تصویر و گویندگی).
- **معماری Provider مستقل:** ۸ ارائه‌دهندهٔ واقعی (دستیار داخلی، Gemini، Groq، OpenRouter، Hugging Face، Jina، Edge-TTS، امبدینگ محلی) با مسیریابی قابلیت‌محور، free-first و fallback؛ کلید BYO هر ارائه‌دهنده فقط به صاحبش می‌رسد؛ وضعیت زنده در تنظیمات دستیار.
- **جست‌وجوی معنایی بانک تمپلیت:** «ریلز لوکس قبل و بعد مو» — با امبدینگ Jina (کلید اختیاری) یا موتور محلیِ آفلاین؛ هر دو واقعی.
- **زیرنویس کارائوکهٔ واقعی:** تایمینگ کلمه‌به‌کلمه از هم‌ترازی انرژی صدا (محلی و آفلاین) — هایلایت دقیقاً هم‌زمان با گفتار، در پیش‌نمایش و خروجی؛ خروجی SRT و VTT.
- **پک خلاقانهٔ زیبایی/مو (Beauty-first):** workflowهای آمادهٔ ریلز قبل/بعد، فیلترها و موسیقی هم‌سبک؛ پک‌های بعدی بدون تغییر هسته اضافه می‌شوند.

## اجرای محلی

```bash
npm install
cp .env.example .env.local   # کلیدها را وارد کن
npm run dev                  # http://localhost:3000
```

## بیلد نسخهٔ گوشی (استاتیک برای GitHub Pages)

```bash
scripts/build-phone.sh jeffstudiio App-Editor   # خروجی: out/
scripts/deploy-pages.sh jeffstudiio App-Editor  # پوش به شاخهٔ gh-pages
```

بیلد گوشی حالت `output: "export"` با basePath `/App-Editor` است و API Routes ندارد؛ بخش‌های AI به سرور نیاز دارند و در نسخهٔ استاتیک غیرفعال‌اند. بقیهٔ اپ (بانک تمپلیت، پیش‌نمایش، ویرایشگر محلی) کامل کار می‌کند.

## ساختار بانک تمپلیت

- تعریف قالب: `src/lib/template-bank/data/*.ts` — هر قالب = اسلات‌های رسانه + صحنه‌های موشن‌دار + متن‌ها
- رسانهٔ پیش‌فرض: `public/bank-media/` (bg / music / posters)
- بستهٔ JSON قابل میزبانی ابری: `public/template-bank/*.json` (از داخل اپ آدرس منبع قابل تعویض است)
- قالب‌های کاربر: IndexedDB (`creative-studio-bank`)

## مجوز رسانه‌ها

تمام ویدئوها، موزیک‌ها و پوسترهای داخل `public/bank-media/` با اسکریپت‌های همین پروژه تولید شده‌اند و بدون محدودیت (CC0) قابل استفاده‌اند.
